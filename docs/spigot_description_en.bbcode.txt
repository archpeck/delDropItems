[B][SIZE=6]DelDropItems[/SIZE][/B]

DelDropItems automatically removes items lying on the ground after a set time. Less clutter in your world, less load on your server. It is lightweight, needs no dependencies and is configured with a single file.

[B][SIZE=5]Features[/SIZE][/B]

[LIST]
[*]Automatic removal of dropped items after a configurable time
[*]Cleanup mode: only items dropped by players, or every item in the world
[*]Ignore list: chosen materials (diamonds, shulker boxes, ...) are never removed
[*]Optional: keep items that have a custom name
[*]Optional: keep items while a player is nearby
[*]Disable the plugin in selected worlds
[*]Periodic chat reminder with [ICODE]%minutes%[/ICODE] / [ICODE]%seconds%[/ICODE] placeholders
[*]Message to the player about the item they dropped
[*]Removal log: who dropped what, where and when
[*]Instant cleanup with [ICODE]/ddi clear[/ICODE]
[*]Messages in 8 languages (English, Russian, French, German, Spanish, Italian, Chinese, Japanese), all texts editable
[/LIST]

[B][SIZE=5]Requirements[/SIZE][/B]

[LIST]
[*]Spigot or Paper (or a fork of them), Minecraft 1.12 or newer
[*]Java 17 or newer
[*]No other plugins are required
[/LIST]

[B][SIZE=5]Installation[/SIZE][/B]

[LIST=1]
[*]Download the latest [ICODE]DelDropItems-x.y.z.jar[/ICODE].
[*]Put the file into your server's [ICODE]plugins[/ICODE] folder.
[*]Start (or restart) the server. The plugin creates [ICODE]plugins/DelDropItems/[/ICODE] with [ICODE]config.yml[/ICODE] and a [ICODE]messages[/ICODE] folder.
[*]Open [ICODE]plugins/DelDropItems/config.yml[/ICODE] and adjust it (see Configuration).
[*]Apply the changes without a restart: [ICODE]/ddi reload[/ICODE].
[/LIST]

To update, stop the server, replace the old JAR with the new one and start the server again. Your [ICODE]config.yml[/ICODE] and message files are kept. New options that are missing from your old [ICODE]config.yml[/ICODE] use their default values; copy them from the new default config if you want to change them.

[B][SIZE=5]Quick start[/SIZE][/B]

The default settings work out of the box: items thrown by players are removed after 5 minutes, and a reminder is broadcast every 5 minutes. A typical customisation looks like this:

[CODE]
language: "en"
item-removal-time: 120
only-player-dropped: true
ignored-materials: [DIAMOND, NETHERITE_INGOT, SHULKER_BOX]
disabled-worlds: [world_nether]
[/CODE]

[B][SIZE=5]Commands[/SIZE][/B]

[LIST]
[*][B]/ddi help[/B] — Show the list of commands you may use — [ICODE]delDropItems.help[/ICODE]
[*][B]/ddi reload[/B] — Reload [ICODE]config.yml[/ICODE] and the message file, restart the timers — [ICODE]delDropItems.reload[/ICODE]
[*][B]/ddi clear[/B] — Remove all matching items right now, ignoring their age — [ICODE]delDropItems.clear[/ICODE]
[*][B]/ddi view-logs[/B] — Show the last 10 removals — [ICODE]delDropItems.view-logs[/ICODE]
[/LIST]

The alias [ICODE]/delDropItems[/ICODE] works too.

[B][SIZE=5]Permissions[/SIZE][/B]

All permissions are granted to operators by default.

[LIST]
[*][B]delDropItems.use[/B] — Allows using the [ICODE]/ddi[/ICODE] command at all
[*][B]delDropItems.help[/B] — [ICODE]/ddi help[/ICODE]
[*][B]delDropItems.reload[/B] — [ICODE]/ddi reload[/ICODE]
[*][B]delDropItems.clear[/B] — [ICODE]/ddi clear[/ICODE]
[*][B]delDropItems.view-logs[/B] — [ICODE]/ddi view-logs[/ICODE]
[*][B]delDropItems.*[/B] — All of the above
[/LIST]

A player needs both [ICODE]delDropItems.use[/ICODE] and the permission of the subcommand. Example with LuckPerms: [ICODE]/lp user Steve permission set delDropItems.use true[/ICODE] and [ICODE]/lp user Steve permission set delDropItems.clear true[/ICODE].

[B][SIZE=5]Configuration[/SIZE][/B]

File: [ICODE]plugins/DelDropItems/config.yml[/ICODE]. After editing, run [ICODE]/ddi reload[/ICODE].

[B][SIZE=4]General[/SIZE][/B]

[LIST]
[*][B]language[/B] — Default: [ICODE]en[/ICODE] — Language of the plugin messages: [ICODE]en[/ICODE], [ICODE]ru[/ICODE], [ICODE]fr[/ICODE], [ICODE]de[/ICODE], [ICODE]es[/ICODE], [ICODE]it[/ICODE], [ICODE]cn[/ICODE], [ICODE]ja[/ICODE]. Applies to chat messages, console output and the removal log, not to the Minecraft interface. An unknown value falls back to English.
[/LIST]

[B][SIZE=4]Removal[/SIZE][/B]

[LIST]
[*][B]item-removal-time[/B] — Default: [ICODE]300[/ICODE] — Seconds an item may lie on the ground before it is removed.
[*][B]only-player-dropped[/B] — Default: [ICODE]true[/ICODE] — [ICODE]true[/ICODE]: only items thrown by players (Q key or dragged out of the inventory). [ICODE]false[/ICODE]: every item entity, including mob drops, broken blocks and death drops.
[*][B]distance-player-to-object[/B] — Default: [ICODE]0[/ICODE] — Distance in blocks. While a player is closer than this to an item, the item is [B]not[/B] removed. [ICODE]0[/ICODE] turns the check off.
[*][B]ignored-materials[/B] — Default: (empty) — Materials that are never removed, e.g. [ICODE][DIAMOND, NETHERITE_INGOT, SHULKER_BOX][/ICODE]. Use the names from the Spigot [ICODE]Material[/ICODE] list. Unknown names are reported in the console.
[*][B]ignore-named-items[/B] — Default: [ICODE]false[/ICODE] — [ICODE]true[/ICODE]: items with a custom name (for example renamed in an anvil) are never removed.
[*][B]disabled-worlds[/B] — Default: (empty) — World names where the plugin does nothing, e.g. [ICODE][world_nether, world_the_end][/ICODE]. Names are case-sensitive.
[/LIST]

[B][SIZE=4]Messages and logging[/SIZE][/B]

[LIST]
[*][B]drop-message-allow[/B] — Default: [ICODE]true[/ICODE] — Send the player a message when they drop an item.
[*][B]reload-message-allow[/B] — Default: [ICODE]true[/ICODE] — Send a message after [ICODE]/ddi reload[/ICODE].
[*][B]broadcast-message-allow[/B] — Default: [ICODE]true[/ICODE] — Periodically broadcast the reminder to all players.
[*][B]broadcast-interval[/B] — Default: [ICODE]300[/ICODE] — Seconds between reminders. [ICODE]0[/ICODE] turns them off.
[*][B]log-removals[/B] — Default: [ICODE]true[/ICODE] — Write every removal to [ICODE]plugins/DelDropItems/logs/item_removal_log.txt[/ICODE].
[/LIST]

[B][SIZE=4]Notes that are worth knowing[/SIZE][/B]

[LIST]
[*][B]Server despawn.[/B] Spigot and Paper remove items by themselves after 6000 ticks (300 seconds). [ICODE]item-removal-time[/ICODE] values above [ICODE]300[/ICODE] only take effect if you also raise [ICODE]item-despawn-rate[/ICODE] in [ICODE]spigot.yml[/ICODE].
[*][B]Loaded chunks only.[/B] Items age and are removed only in chunks that are loaded.
[*][B]Who counts as "dropped by a player".[/B] The plugin uses the thrower stored on the item. Items from mobs, blocks, hoppers or commands have no thrower, so with [ICODE]only-player-dropped: true[/ICODE] they are left alone.
[*][B][ICODE]/ddi clear[/ICODE][/B] ignores age and the nearby-player check, but still respects [ICODE]only-player-dropped[/ICODE], [ICODE]ignored-materials[/ICODE], [ICODE]ignore-named-items[/ICODE] and [ICODE]disabled-worlds[/ICODE].
[/LIST]

[B][SIZE=5]Messages[/SIZE][/B]

Message files are stored in [ICODE]plugins/DelDropItems/messages/messages_<language>.yml[/ICODE]. They are created from the built-in defaults the first time a language is used and are never overwritten afterwards, so you can edit them freely. If a key is missing from your file, the built-in text is used.

Colour codes: use [ICODE]§[/ICODE] or [ICODE]&[/ICODE], for example [ICODE]&a[/ICODE] for green and [ICODE]&l[/ICODE] for bold.

[LIST]
[*][B]prefix[/B] — Prefix in front of command replies
[*][B]broadcast-message[/B] — Periodic reminder — Placeholders: [ICODE]%minutes%[/ICODE], [ICODE]%seconds%[/ICODE]
[*][B]drop-message[/B] — Message to the player who dropped an item — Placeholders: [ICODE]%item_name%[/ICODE]
[*][B]reload-message[/B] — After [ICODE]/ddi reload[/ICODE]
[*][B]clear-message[/B] — After [ICODE]/ddi clear[/ICODE] — Placeholders: [ICODE]%count%[/ICODE]
[*][B]no-permission[/B] — Missing permission
[*][B]unknown-command[/B] — Unknown subcommand
[*][B]logs-header, logs-empty[/B] — [ICODE]/ddi view-logs[/ICODE] output
[*][B]help-header, help-reload, help-clear, help-logs, help-help[/B] — [ICODE]/ddi help[/ICODE] output
[*][B]console-enabled[/B] — Console line on startup — Placeholders: [ICODE]%version%[/ICODE]
[*][B]console-unknown-material, console-language-missing, console-folder-error, console-file-error, console-log-error[/B] — Console warnings and errors — Placeholders: [ICODE]%name%[/ICODE], [ICODE]%language%[/ICODE], [ICODE]%error%[/ICODE]
[*][B]log-removal[/B] — One line of the removal log — Placeholders: [ICODE]%time%[/ICODE], [ICODE]%item%[/ICODE], [ICODE]%amount%[/ICODE], [ICODE]%player%[/ICODE], [ICODE]%world%[/ICODE], [ICODE]%x%[/ICODE], [ICODE]%y%[/ICODE], [ICODE]%z%[/ICODE]
[*][B]log-unknown-player[/B] — Name used in the log when the thrower is unknown
[/LIST]

[ICODE]%minutes%[/ICODE] is the removal time in whole minutes (at least 1). For removal times under a minute use [ICODE]%seconds%[/ICODE].

[B][SIZE=5]Removal log[/SIZE][/B]

If [ICODE]log-removals[/ICODE] is on, every removed item is appended to [ICODE]plugins/DelDropItems/logs/item_removal_log.txt[/ICODE]:

[CODE]
[2026-11-07 18:42:10] Item: DIAMOND x3, dropped by: Steve, world: world (120, 64, -45) has been removed.
[/CODE]

The log is written in the language selected in [ICODE]language[/ICODE]. If the thrower is not known, [ICODE]unknown[/ICODE] (translated) is written instead of the name. If the player is offline, their UUID is written. The last 10 lines are available in game with [ICODE]/ddi view-logs[/ICODE].

[B][SIZE=5]FAQ[/SIZE][/B]

[B]Items are not removed.[/B]
Check that: the item was thrown by a player (or [ICODE]only-player-dropped[/ICODE] is [ICODE]false[/ICODE]); its material is not in [ICODE]ignored-materials[/ICODE]; the world is not in [ICODE]disabled-worlds[/ICODE]; no player is within [ICODE]distance-player-to-object[/ICODE]; the item is in a loaded chunk; enough time has passed.

[B]Items disappear faster than [ICODE]item-removal-time[/ICODE].[/B]
Spigot/Paper despawn items after 300 seconds by default, and other plugins may also clean items. Check [ICODE]spigot.yml[/ICODE] and your other cleanup plugins.

[B]I get "Unknown material" in the console.[/B]
A name in [ICODE]ignored-materials[/ICODE] does not exist in your Minecraft version. Use uppercase Spigot names such as [ICODE]NETHERITE_INGOT[/ICODE].

[B]Messages are not in my language.[/B]
Check [ICODE]language[/ICODE] in [ICODE]config.yml[/ICODE] and run [ICODE]/ddi reload[/ICODE]. If you changed the language after editing a message file, the new language's file is created separately: [ICODE]messages_<language>.yml[/ICODE].

[B]The plugin does not load.[/B]
Check the console for the exact error. Make sure the server runs Java 17 or newer.

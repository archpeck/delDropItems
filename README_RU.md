DelDropItems автоматически удаляет предметы, лежащие на земле, через заданное время. Меньше мусора в мире и меньше нагрузки на сервер. Плагин лёгкий, не требует других плагинов и настраивается одним файлом.

## Возможности

- Автоматическое удаление выброшенных предметов через настраиваемое время
- Режим очистки: только предметы, выброшенные игроками, или любые предметы в мире
- Список исключений: выбранные материалы (алмазы, шалкеры и т. д.) никогда не удаляются
- Опция: не удалять предметы с кастомным названием
- Опция: не удалять предметы, пока рядом находится игрок
- Отключение плагина в выбранных мирах
- Периодическое напоминание в чат с плейсхолдерами `%minutes%` / `%seconds%`
- Сообщение игроку о том, что он выбросил
- Журнал удалений: кто, что, где и когда выбросил
- Мгновенная очистка командой `/ddi clear`
- Сообщения на 8 языках (английский, русский, французский, немецкий, испанский, итальянский, китайский, японский), все тексты можно править

## Требования

- Spigot или Paper (или их форк), Minecraft 1.17 и новее (более старые версии не поддерживаются)
- Java 17 или новее
- Другие плагины не нужны

## Установка

1. Скачайте последний `DelDropItems-x.y.z.jar`.
2. Положите файл в папку `plugins` вашего сервера.
3. Запустите (или перезапустите) сервер. Плагин создаст папку `plugins/DelDropItems/` с файлом `config.yml` и папкой `messages`.
4. Откройте `plugins/DelDropItems/config.yml` и настройте его (см. раздел «Настройка»).
5. Примените изменения без перезапуска командой `/ddi reload`.

Чтобы обновить плагин, остановите сервер, замените старый JAR новым и запустите сервер снова. Ваш `config.yml` и файлы сообщений сохранятся. Новые опции, которых нет в вашем старом `config.yml`, используют значения по умолчанию; если хотите их изменить, скопируйте их из нового конфига по умолчанию.

## Быстрый старт

Настройки по умолчанию работают сразу: предметы, выброшенные игроками, удаляются через 5 минут, а напоминание в чат приходит каждые 5 минут. Типичная настройка выглядит так:

```yaml
language: "ru"
item-removal-time: 120
only-player-dropped: true
ignored-materials: [DIAMOND, NETHERITE_INGOT, SHULKER_BOX]
disabled-worlds: [world_nether]
```

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/ddi help` | Показать список доступных вам команд | `delDropItems.help` |
| `/ddi reload` | Перезагрузить `config.yml` и файл сообщений, перезапустить таймеры | `delDropItems.reload` |
| `/ddi clear` | Удалить все подходящие предметы прямо сейчас, не учитывая их возраст | `delDropItems.clear` |
| `/ddi view-logs` | Показать последние 10 удалений | `delDropItems.view-logs` |

Работает и псевдоним `/delDropItems`.

## Права

По умолчанию все права выданы операторам.

| Право | Описание |
|---|---|
| `delDropItems.use` | Разрешает пользоваться командой `/ddi` вообще |
| `delDropItems.help` | `/ddi help` |
| `delDropItems.reload` | `/ddi reload` |
| `delDropItems.clear` | `/ddi clear` |
| `delDropItems.view-logs` | `/ddi view-logs` |
| `delDropItems.*` | Все права выше |

Игроку нужны оба права: `delDropItems.use` и право подкоманды. Пример для LuckPerms: `/lp user Steve permission set delDropItems.use true` и `/lp user Steve permission set delDropItems.clear true`.

## Настройка

Файл: `plugins/DelDropItems/config.yml`. После правки выполните `/ddi reload`.

### Общее

| Опция | По умолчанию | Описание |
|---|---|---|
| `language` | `en` | Язык сообщений плагина: `en`, `ru`, `fr`, `de`, `es`, `it`, `cn`, `ja`. Влияет на сообщения в чате, вывод в консоль и журнал удалений, но не на интерфейс Minecraft. Неизвестное значение заменяется английским. |

### Удаление

| Опция | По умолчанию | Описание |
|---|---|---|
| `item-removal-time` | `300` | Сколько секунд предмет может лежать на земле до удаления. Минимум `1`. |
| `only-player-dropped` | `true` | `true`: только предметы, выброшенные игроками (клавиша Q или вытащенные из инвентаря). `false`: любые предметы, включая дроп с мобов, сломанных блоков и после смерти. |
| `distance-player-to-object` | `0` | Расстояние в блоках. Пока рядом с предметом (ближе этого значения) есть игрок, предмет **не** удаляется. `0` отключает проверку. |
| `ignored-materials` | `[]` | Материалы, которые никогда не удаляются, например `[DIAMOND, NETHERITE_INGOT, SHULKER_BOX]`. Используйте названия из списка `Material` в Spigot. Неизвестные названия выводятся в консоль. |
| `ignore-named-items` | `false` | `true`: предметы с кастомным названием (например, переименованные на наковальне) никогда не удаляются. |
| `disabled-worlds` | `[]` | Названия миров, где плагин ничего не делает, например `[world_nether, world_the_end]`. Регистр важен. |

### Сообщения и журнал

| Опция | По умолчанию | Описание |
|---|---|---|
| `drop-message-allow` | `true` | Отправлять игроку сообщение, когда он выбрасывает предмет. |
| `reload-message-allow` | `true` | Отправлять сообщение после `/ddi reload`. |
| `broadcast-message-allow` | `true` | Периодически отправлять напоминание всем игрокам. |
| `broadcast-interval` | `300` | Секунд между напоминаниями. `0` отключает их. |
| `log-removals` | `true` | Записывать каждое удаление в `plugins/DelDropItems/logs/item_removal_log.txt`. |

### Что полезно знать

- **Деспавн сервера.** Spigot и Paper сами удаляют предметы через 6000 тиков (300 секунд). Значения `item-removal-time` больше `300` сработают, только если вы также увеличите `item-despawn-rate` в `spigot.yml`.
- **Только загруженные чанки.** Предметы «стареют» и удаляются только в загруженных чанках.
- **Что значит «выброшен игроком».** Плагин использует данные о том, кто бросил предмет, которые хранятся в самом предмете. У предметов от мобов, блоков, воронок или команд такого игрока нет, поэтому при `only-player-dropped: true` они не трогаются.
- **`/ddi clear`** не учитывает возраст и близость игроков, но учитывает `only-player-dropped`, `ignored-materials`, `ignore-named-items` и `disabled-worlds`.

## Сообщения

Файлы сообщений лежат в `plugins/DelDropItems/messages/messages_<язык>.yml`. Они создаются из встроенных шаблонов при первом использовании языка и больше не перезаписываются, поэтому их можно свободно править. Если какого-то ключа в вашем файле нет, используется встроенный текст.

Цветовые коды: используйте `§` или `&`, например `&a` для зелёного и `&l` для жирного.

| Ключ | Для чего | Плейсхолдеры |
|---|---|---|
| `prefix` | Префикс перед `no-permission`, `unknown-command`, `clear-message` и `logs-empty`. В `broadcast-message`, `drop-message` и `reload-message` префикс записан прямо в тексте, меняйте его там | |
| `broadcast-message` | Периодическое напоминание | `%minutes%`, `%seconds%` |
| `drop-message` | Сообщение игроку, выбросившему предмет | `%item_name%` |
| `reload-message` | После `/ddi reload` | |
| `clear-message` | После `/ddi clear` | `%count%` |
| `no-permission` | Нет прав | |
| `unknown-command` | Неизвестная подкоманда | |
| `logs-header`, `logs-empty` | Вывод `/ddi view-logs` | |
| `help-header`, `help-reload`, `help-clear`, `help-logs`, `help-help` | Вывод `/ddi help` | |
| `console-enabled` | Строка в консоли при запуске | `%version%` |
| `console-unknown-material`, `console-language-missing`, `console-folder-error`, `console-file-error`, `console-log-error` | Предупреждения и ошибки в консоли | `%name%`, `%language%`, `%error%` |
| `log-removal` | Одна строка журнала удалений | `%time%`, `%item%`, `%amount%`, `%player%`, `%world%`, `%x%`, `%y%`, `%z%` |
| `log-unknown-player` | Имя в журнале, если бросивший неизвестен | |

`%minutes%` — время удаления в целых минутах (не меньше 1). Если время удаления меньше минуты, используйте `%seconds%`.

## Журнал удалений

Если включён `log-removals`, каждый удалённый предмет дописывается в `plugins/DelDropItems/logs/item_removal_log.txt`:

```
[2026-11-07 18:42:10] Предмет: DIAMOND x3, выбросил: Steve, мир: world (120, 64, -45) удалён.
```

Журнал пишется на языке из `language`. Если бросивший игрок неизвестен, вместо имени пишется «неизвестен» (на выбранном языке). Если игрок не в сети, пишется его UUID. Последние 10 строк доступны в игре командой `/ddi view-logs`.

## Частые вопросы

**Предметы не удаляются.**
Проверьте: предмет выброшен игроком (или `only-player-dropped` равен `false`); его материала нет в `ignored-materials`; мира нет в `disabled-worlds`; рядом нет игрока ближе `distance-player-to-object`; предмет лежит в загруженном чанке; прошло достаточно времени.

**Предметы исчезают быстрее, чем `item-removal-time`.**
Spigot/Paper по умолчанию удаляют предметы через 300 секунд, и их могут чистить другие плагины. Проверьте `spigot.yml` и другие плагины очистки.

**В консоли пишет «Unknown material».**
Название в `ignored-materials` не существует в вашей версии Minecraft. Регистр не важен (`diamond` тоже подойдёт); сверьте написание со списком `Material` в Spigot для вашей версии сервера, например `NETHERITE_INGOT` есть только с 1.16.

**Сообщения не на моём языке.**
Проверьте `language` в `config.yml` и выполните `/ddi reload`. Если вы сменили язык после правки файла сообщений, файл нового языка создаётся отдельно: `messages_<язык>.yml`.

**Плагин не загружается.**
Посмотрите точную ошибку в консоли. Убедитесь, что сервер работает на Java 17 или новее.
